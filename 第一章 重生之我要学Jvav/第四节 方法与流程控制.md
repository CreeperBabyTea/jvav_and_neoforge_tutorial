# 方法与流程控制

学习目标：学会创建方法、调用方法；使用条件语句、循环语句控制运行流程  
内容要点：

- 方法的声明
    - 返回值
    - 形参
- 条件语句(if, if-else, if-else-if, switch)
- 三目运算符
- 循环语句(for, foreach, while, do-while)
    - 循环控制(loop, break, continue)

## 方法

方法，长得跟C艹的函数一样，嗯

方法包含五个部分：

- 修饰符
- 返回值类型
- 方法名
- 形参
- 方法体

一个方法用伪代码表示就是

```
修饰符 返回值类型 方法名(形参类型1 形参1, 形参类型2 形参2, ...) {
  方法体;
}
```

**特别的**，构造器可以视为一种不显式指定返回值、而是返回该类的实例的静态方法。

其中修饰符就是我们上一节提到的访问控制修饰符等。为了绕开OOP相关的问题，我们目前所有方法都用static修饰。

### 返回值

我们运行一个方法后，怎么样才能知道这个方法运行的结果呢？为此，方法可以具有返回值。返回返回值的语句形如`return 返回值;`

返回值的类型我们在方法的声明中做出了规定。特别的，如果方法无返回值，我们可以设置其返回类型为`void`，则此方法不需要`return`
语句。

比如，下面是一个简单的返回"meow"这一字符串的一个方法：

```java
public static String getCatSound() {
    return "meow";
}
```

### 形参

形参即形式参数，为输入方法的信息。比如我们下面写这样一个方法：

```java
public static int add(int a, int b) {
    return a + b;
}
```

这里我们传入了a和b，a和b传递到形参后，他们便作为实参(实际参数)参与方法的调用。

## 流程控制

### 条件语句

条件语句分为两种：if-else和switch-case，以及特殊的三目运算符。我们分别讲解。

#### if-else

这个语句的写法为：

```
if (条件判断) {
    /* 语句 */
} else {
    /* 语句 */
}
```

其中，条件判断就是一个类型为boolean的表达式。它既可以是一个简单的大小比较，也可以是某些布尔型的方法，比如
`String.isEmpty()`  
下面这个方法会判断数组长度是否为零：

```java
static void isEmpty(int[] arrayIn) {
    if (arrayIn.length == 0)
        System.out.println("Empty array found!");
}
```

这里你应该注意到了：

1. 如果if下只有一条语句，则可以省略花括号。但是，这条语句不能是变量的声明，否则过不了编译。
2. 如果没有必要使用else语句，则可以直接省略else语句。

然后，else后面可以直接接上if，形如

```
if (条件判断) {
    /* 语句 */
} else if (另一个条件) {
    /* 语句 */
} else {
    /* 语句 */
} 
```

这里需要区别使用else if和多个if并列的情况。举个简单的例子，下面有两个程序：
```java
/**
 * @param value any integer within 0~100
 */
public static void methodA(int value) {
    if (value < 100)
        System.out.println("Value is smaller than 100!");
    else if (value < 80)
        System.out.println("Value is smaller than 80!");
    else if (value < 60)
        System.out.println("Value is smaller than 60!");
}
```

```java
/**
 * @param value any integer within 0~100
 */
public static void methodB(int value) {
    if (value < 100)
        System.out.println("Value is smaller than 100!");
    if (value < 80)
        System.out.println("Value is smaller than 80!");
    if (value < 60)
        System.out.println("Value is smaller than 60!");
}
```

对于两个方法，我们都输入90，则都会输出`Value is smaller than 100!`。  
但是如果我们输入50，methodA只会输出`Value is smaller than 100!`，而methodB会输出
```
Value is smaller than 100!
Value is smaller than 80!
Value is smaller than 60!
```
这是因为，在methodA中，因为50<100为true，所以只有if下的语句被调用，而else后的一切if和else if均被跳过；
而在methodB中，三个if会逐个判断，而不是因为第一个if通过了，就不去判断第二个if，因此三条提示都出现了。

#### switch-case
如果有多个对同一个表达式判断的if-else，则代码会很臃肿，且严重影响性能。对此，我们可以使用switch-case语句。其语法如下：
```
switch(变量) {
    case 预期值1: {
        /* 语句 */
        break;
    }
    case 预期值2: {
        /* 语句 */
        break;
    }
    /* ... */
    default: {
        /* 语句 */
    }
}
```
其中变量可以是数字、字符、字符串、枚举(面向对象讲zzz)。
这里很简单，switch会拿着这个变量逐个比对，当某一个case的预期值与变量相同时，则执行这个case块的代码。  
case块一般都要求有break语句，break可以让switch停止运行，否则从第一个成功匹配的case开始，后续所有case和default的代码都会执行。这里理解不了可以自己试一试。  
如果switch拿着这个变量走了一圈，没找到一样的case块，switch就会执行default中的代码。default块可以不存在，但是如果存在，则必须在最后一个写。

如果有多个预期值希望实现相同操作，则可以讲他们放在一起，且仅保留最后一个case块的代码，其他case块一律擦掉代码块，如
```
/* ... */
case 1:
case 2:
case 3:
case 4:
    System.out.println("meow");
    break;
/* ... */
```

同时，Java还引入了强化的switch块，其形式如下：
```
switch (变量) {
    case 值1 -> 返回值1;
    case 值2 -> 返回值2;
    /* ... */
    default -> 默认返回值;
};
```
这种switch块是具有返回值的，且无需break。它可以提供更加便捷的赋值操作，如
```
String dayType = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "无效日期";
};
```

#### 三目运算符
三目运算符，即`?:`。其语法如下：
`条件 ? 若真，返回值 : 若假，返回值;`
例如：
```
int number = 7;
String numberType = (number % 2 == 0) ? "偶数" : "奇数";
```
这个对于if-else，就像强化的switch-case对未强化的。

### 循环语句

循环语句主要有for, while, do-while三种。我们依然逐个讲解：

#### for

for的语法是：
`for (初始化; 条件; 迭代) {/* ... */}`
- 初始化部分，是在for循环开始之前调用。这里一般我们会定义引索index。
- 条件部分，每次循环开始前判断。若为真，则进行循环；若为假，则循环结束。
- 迭代，在每次循环的末尾执行。一般用于更新引索。

for语句除了条件不可省略，初始化、迭代和代码块都可以不存在。所以下面这个for完全合法(但是死循环)：
`for (;true;)`  
与if-else相同，如果代码块只有一条语句，for允许省略花括号。

例如，下面这个循环输出了整数0~9：
```
for (int i = 0; i < 10; i ++)
    System.out.println(i);
```

#### while

while语句就是没有初始化和迭代的for语句，即
`while(条件) {/* ... */}`

#### do-while

do-while语法如下：

```
do {
    /* ... */
} while(条件)
```

do-while会先执行一次，无论条件，然后其行为就与while无异。

#### 标签、continue与break

对于循环，我们如果需要结束循环，或跳过本次循环，就可以使用上述转向语句。

continue的作用是跳过本次循环的剩余代码，直接开始下一次循环(当然还是要条件判断的)，
break的作用是直接结束循环，跳出循环。

如果有多层循环嵌套，break和continue会作用于最内层循环。如果我们需要跳出外层循环，就必须使用标签。
标签形如`标签名:`，其中标签名与变量名命名原则相同。标签应放在其对应循环的上一行。例子：
```
outerLoop: // 标签
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i * j == 4) {
            break outerLoop; // 直接跳出外层循环
        }
    }
}
```
