## 变量的声明与赋值

声明变量  
`数据类型 变量名;`

声明并初始化  
`数据类型 变量名 = 初始值;`

同时声明多个变量  
`数据类型 变量1, 变量2, 变量3;`

变量必须先声明后使用， 局部变量在使用前必须初始化，而实例变量和类变量有默认值(如 int 默认值为 0，引用类型默认值为null)
，这一点不需要记住，你后面写代码慢慢就理解了

变量名要求与类名一致，你可以自行翻阅。

除此之外，我们还有一些命名习惯

- 使用ascii字符命名，使用a-zA-Z0-9以及_中的字符命名
- 对于常量，使用全大写，单词之间使用下划线`_`分隔
- 对于变量，使用小驼峰式，除第一个单词外，所有单词首字母大写，其余字母全部小写。

这个命名习惯你不遵循也行，但是容易被你组里其他人打死

## 基本数据类型

Java 有 8 种基本数据类型：

- 整型：byte, short, int, long
- 浮点型：float, double
- 字符型：char
- 布尔型：boolean

需要注意，浮点型默认是double，也就是说，形如`1.0`的数类型是double。要强调是float，则要在数后写`F`，如`1.0F`即为float。
同时，若浮点型的整数部分为0，则Java允许省略不写。也就是说你可以直接写`.5F`。

与C艹不同，Java的布尔型使用`boolean`定义，且不可与其他数据类型混用。

除此之外，还有引用类型。引用类型涉及对象的创建，我们放到OOP之后讲。

## String

String类似C艹中的cstring头文件或string.h头文件，提供字符串的支持。String是一种引用类型，但是它体现不出很多引用类型的特征，所以我们在讲OOP之前并不避讳它。

String的值可以直接用双引号表示，这一点和C++相同。我们可以定义：`String myFavoriteGame = "Genshin Impact"`。  
同样的，转义(如\n)也可以直接用在String中。

String类型有几个特别的方法：

- int length() 返回字符串长度。
- boolean isEmpty() 返回字符串是否长度为0，即是否是空字符串。
- char charAt(int index) 返回指定序号的字符。其中，第一个字符的index是0，最后一个字符的index是length() - 1。
- boolean contains(CharSequence s) 搜索是否包含指定字符串。CharSequence即字符序列，是String实现的接口，所以你可以直接用一个String作为方法实参。如`"Fabled Hyperion".contains("peri")   // true`
- boolean matches(String regex) 检测是否匹配正则表达式regex。正则表达式是一种强大的字符串匹配机制。感兴趣可以自学。

## 数组

Java中数组定义语法为：
`类型[] 变量名;`  
创建直接指定值的数组语法为：
`{val1, val2, val3, ...};`  
创建指定容量、默认值的数组语法为：
`new 类型[容量];`  
这里的默认值，指的是类型的默认值。对于数字类型，其默认值为0；对于char，其默认值为\u000；对于布尔型，其默认值为false；对于引用类型，其默认值为null。

访问数组中的元素可以使用`数组名[序号]`。
数组有一个自带的字段length，可以通过`数组名.length`访问。

在我们学习面向对象前，请尽量避免将一个数组赋值给另一个数组的行为。

## 类型转换

我们学校的C艹课已经学到了整形、浮点型的容量。对于小容量数转为大容量数，java允许自动转型，你不需要强制转型。  
但是，对于除法，除法算式的类型跟随分子的类型。所以如果你进行除法时，分子是单精度浮点，而结果需要双精度浮点，这时java不知道需要转型，所以你必须强制转型。

在这之外，必要时你可以强制转型。强制转型的语法很简单，`(目标类型)变量名`。这是一个语句，它并非将原变量转型，而是说你可以将这个转型后的值赋给其他变量。如

```java
long a = 114514L;
int b = (int) a;
```

这里结束后a仍是long，而b是int。

## var

在定义局部变量时，我们允许使用var声明变量。var会自动推断变量类型，如下：
`var a = 1;   //a的类型是int`

注意，var不能在声明全局变量时使用。
